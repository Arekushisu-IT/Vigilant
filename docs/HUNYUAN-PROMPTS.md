# Hunyuan3D: models for you to generate online

**Where:** the Hunyuan3D website (3d.hunyuan.tencent.com) or the free Hugging Face demo "tencent/Hunyuan3D-2". Sign in yourself.

**Settings for every model:**
- **Mode:** text to 3D. Paste the prompt; if the result is poor, try "image to 3D" with a reference photo.
- **Texture:** ON (textured / PBR).
- **Face count:** people about 30,000–50,000; props about 10,000–20,000. Use "low" or "medium" if the site has no number.
- **Export:** **GLB**.
- **Save to:** `C:\Users\ADMIN\Desktop\Dev Apps\Vigilant\art\generated\`, using the file name given for each model.

**Rules for the prompts:**
- Use a full body, a neutral background, and a single object.
- Use no logos or brand names, and no real people.
- If a person comes out with a chair attached, that's fine; keep it.
